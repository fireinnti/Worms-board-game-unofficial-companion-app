# UI font sources

The app loads these font files at runtime with `expo-font` and retains system font fallbacks while they are unavailable:

- **Bungee Regular** (headings), Copyright 2016 The Bungee Project Authors, licensed under the SIL Open Font License 1.1: `https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/bungee/Bungee-Regular.ttf`
- **Atkinson Hyperlegible Next Regular** (rules text), Copyright 2019–2025 Braille Institute of America, Inc., licensed under the SIL Open Font License 1.1: `https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/atkinsonhyperlegiblenext/AtkinsonHyperlegibleNext%5Bwght%5D.ttf`

The authoritative [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/) applies to both families. No font binaries are committed, keeping source-only review and patch tooling compatible.
