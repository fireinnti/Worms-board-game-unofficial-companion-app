# UI asset provenance

All SVG artwork in this folder (`battlefield-horizon.svg`, `smoke-explosion.svg`, `panel-edge.svg`, and `crate-target.svg`) was drawn specifically for this companion app in September 2026. It uses only generic landscape, smoke, burst, paper, crate, and target geometry; it does not reproduce commercial game characters or artwork.

These original assets are released with this project under the project's license. There are no non-original visual assets in this folder. Font attribution and licensing are documented in `../fonts/README.md`.
